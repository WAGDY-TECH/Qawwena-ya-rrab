## 📋 عن المشروع

**قوينا يا رب** هو نظام متكامل لتتبع خطط سداد الديون مصمم خصيصًا للمستخدمين الناطقين بالعربية. يساعدك هذا النظام على:

- إنشاء خطط سداد مخصصة للدين
- تتبع الأقساط الشهرية
- تسجيل الدفعات بدقة
- عرض الإحصائيات والتقدم
- تصدير واستيراد البيانات
- طباعة التقارير

---

## ✨ الميزات

### في الإصدار الأصلي (`debt_repayment_plan.html`)

✅ واجهة مستخدم عربية كاملة مع دعم RTL  
✅ تصميم عصري وجذاب  
✅ تسجيل الدفعات لكل قسط  
✅ إحصائيات في الوقت الفعلي  
✅ شريط تقدم مرئي  
✅ تنبيهات للأقساط القريبة أو المتأخرة  
✅ نظام توقيع إلكتروني  
✅ تصدير واستيراد البيانات (JSON)  
✅ طباعة التقارير  
✅ حفظ البيانات محليًا (localStorage)  

### في الإصدار المحسّن (`debt_repayment_plan_enhanced.html`)

🎯 **جميع ميزات الإصدار الأصلي +**  
✅ **تعديل الأقساط** - تعديل أي قسط موجود  
✅ **إضافة أقساط جديدة** - إضافة أقساط يدويًا  
✅ **حذف الأقساط** - إزالة الأقساط غير الضرورية  
✅ **ملاحظات على الأقساط** - إضافة ملاحظات لكل قسط  
✅ **فلترة الأقساط** - عرض حسب الحالة (جميعها، مدفوعة، قادمة، متأخرة، بملاحظات)  
✅ **الرسوم البيانية** - عرض مرئي لتقدم السداد  
✅ **نسب المساهمة** - عرض نسبة كل شخص في السداد  
✅ **تذكير بنسخ الاحتياطي** - تذكير تلقائي بنسخ البيانات  
✅ **اختصارات لوحة المفاتيح** - Ctrl+P (طباعة), Ctrl+S (تصدير)  
✅ **تحسينات في التحقق من البيانات** - رسائل خطأ واضحة  
✅ **دعم DPI العالي** - رسم التوقيع بشكل صحيح على جميع الشاشات

## 🚀 كيفية الاستخدام

### الطريقة 1: الاستخدام المحلي

1. حمّل الملف `debt_repayment_plan.html` أو `debt_repayment_plan_enhanced.html`
2. افتحه في أي متصفح حديث (Chrome, Firefox, Safari, Edge)
3. املأ استمارة الإعداد:
   - إجمالي قيمة الدين
   - القسط الشهري
   - حصة وجدي الشهرية
   - حصة شعبان الشهرية
   - تاريخ أول قسط
   - يوم السداد الشهري
4. انقر على "حفظ وبدء الخطة"
5. بدء تسجيل الدفعات

### الطريقة 2: من GitHub Pages

إذا تم تمكين GitHub Pages:
1. اذهب إلى: `https://wagdy-tech.github.io/Qawwena-ya-rrab/`
2. اختر الملف الذي تريد استخدامه
3. اتبع نفس خطوات الإعداد

## 💾 حفظ البيانات

جميع البيانات يتم حفظها تلقائيًا في:
- **localStorage** - في المتصفح الذي تستخدمه
- **ملفات JSON** - عند تصدير البيانات يدويًا

⚠️ **ملاحظة مهمة**: البيانات مخزنة محليًا فقط. قم بنسخها احتياطيًا بانتظام باستخدام زر "تصدير البيانات".

---

## ⌨️ اختصارات لوحة المفاتيح (الإصدار المحسّن)

| الاختصار | الوصف |
|----------|------|
| `Ctrl + P` | طباعة الصفحة |
| `Ctrl + S` | تصدير البيانات |
| `Ctrl + E` | تصدير البيانات |
| `Escape` | إغلاق النوافذ المنبثقة |
